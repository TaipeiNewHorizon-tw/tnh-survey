① 系統說明

本系統為臺北文創（Taipei New Horizon）專用的線上場地體驗滿意度問卷平台，用於收集活動租場客戶的使用反饋，協助持續改善場地設施與服務品質。

主要功能

  • 手機／電腦均可填寫的響應式問卷介面
  • 支援五等量表（非常滿意 ～ 非常不滿意）、單選、多選、文字等題型
  • 後台即時統計分析（圓形圖、KPI 摘要）
  • 填寫紀錄查詢、CSV 匯出
  • QR Code 掃碼 / Email 邀請連結雙管道，自動標記來源
  • 多人員帳號管理（管理員 / 一般人員）

③ 填寫管道

📱 QR Code 掃碼

將 QR Code 印製於場地現場或活動現場，受訪者掃碼直接開啟問卷。系統自動標記來源為「QR Code 掃碼」，方便後台統計各管道填寫比例。

📧 Email 邀請

後台「發送邀請」功能可開啟信箱，發送含問卷連結的邀請信。系統自動於連結附加 ?source=email，後台可篩選查看 Email 邀請的填寫結果。

🔗 直接連結

直接分享問卷網址給受訪者，填寫來源標記為「直接開啟」。

④ 後台管理說明

登入方式

開啟 /admin 路徑，輸入帳號密碼登入。帳號由管理員在後台「帳號管理」分頁新增。

各功能分頁

  • 題目管理 — 檢視、編輯、排序、上下架題目
  • 新增題目 — 新增各種題型的題目
  • 統計分析 — 圓形圖顯示各題平均分數與分布；KPI 摘要顯示整體平均、非常滿意占比、總回應數
  • 填寫紀錄 — 逐筆查閱每份問卷內容，支援分頁
  • 發送邀請 — 開啟信箱寄送邀請信
  • 帳號管理（管理員限定）— 新增/停用人員帳號、設定刪除密碼
  • 操作紀錄（管理員限定）— 查閱所有後台操作歷程

CSV 匯出

後台側邊欄底部「⬇ 下載 CSV」按鈕可匯出全部填寫資料，可用 Excel 開啟分析。

⑤ 技術架構

後端框架
Node.js + Express
資料庫
SQLite（node:sqlite 內建）
部署平台
Railway（Hobby Plan）
身份驗證
express-session + bcryptjs
前端
HTML / CSS / 原生 JS（無框架）
程式碼儲存
GitHub（TaipeiNewHorizon-tw）

資料流程

  • 填寫者開啟問卷 → 前端讀取 /api/questions
  • 送出後存入 SQLite（responses + answers 資料表）
  • 後台登入後透過各 /api/admin/* 端點存取資料
  • 統計分析由後端即時計算後回傳，前端以 SVG 圓形圖呈現
