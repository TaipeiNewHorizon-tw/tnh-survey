臺北文創場地參與體驗滿意度調查 — 問卷題目清單
========================================================
說明：
- 每一題格式為【分類】題號. 題目內容
- 題目類型與選項標注於每題下方
- 修改後可交給 IT 人員更新系統
========================================================


【基本資料】

1. 參與活動名稱
   類型：簡短文字　必填：是

2. 廳別
   類型：簡短文字　必填：否

3. 活動日期
   類型：日期　必填：否

4. 填表人
   類型：簡短文字　必填：否


【場地體驗滿意度】

5. 您覺得本次活動場地（臺北文創）的「周邊指引」如何？
   類型：五等量表　選項：非常滿意 / 滿意 / 普通 / 不滿意 / 非常不滿意
   附加建議欄：是　必填：是

6. 進入大樓及活動會場的「動線指引與標示」是否清晰易懂？
   類型：五等量表　選項：非常滿意 / 滿意 / 普通 / 不滿意 / 非常不滿意
   附加建議欄：是　必填：是

7. 您對活動現場的「影音播放效果」是否滿意？
   類型：五等量表　選項：非常滿意 / 滿意 / 普通 / 不滿意 / 非常不滿意
   附加建議欄：是　必填：是

8. 您對活動現場的「空調溫度及環境隔音（是否受干擾）」是否滿意？
   類型：五等量表　選項：非常滿意 / 滿意 / 普通 / 不滿意 / 非常不滿意
   附加建議欄：是　必填：是

9. 您對公共區域（如洗手間、廳內、茶水間）的「整潔程度」是否滿意？
   類型：五等量表　選項：非常滿意 / 滿意 / 普通 / 不滿意 / 非常不滿意
   附加建議欄：是　必填：是

10. 本次活動期間，場地服務人員及一樓引導人員的服務態度是否令您滿意？
    類型：五等量表　選項：非常滿意 / 滿意 / 普通 / 不滿意 / 非常不滿意
    附加建議欄：是　必填：是


【綜合反饋】

11. 未來若有其他感興趣的活動是否會向其他人推薦臺北文創場地？
    類型：單選　選項：會 / 不會
    附加原因欄：是　必填：是

12. 對於本次的場地空間與環境，您是否有其他具體的批評或建議？
    類型：長文字（開放式填寫）　必填：否


========================================================
題目類型說明：
  簡短文字 — 單行開放式輸入
  長文字   — 多行開放式輸入
  日期     — 日期選擇器
  五等量表 — 非常滿意／滿意／普通／不滿意／非常不滿意
  單選     — 自訂選項，只能選一個
  多選     — 自訂選項，可選多個
